# 자사주 CHECK (Buyback-Korea)

국내 상장사의 **자기주식 취득·소각·처분 결정**과 **기업가치 제고 계획(밸류업) 공시**를 매일 자동 수집해
시가총액 대비 규모, 발행주식수 대비 비율, 공시 후 주가 반응(D+1 · 5거래일 · 20거래일 · 현재, 지수 대비 초과수익)까지
한 화면에서 비교하는 사이트입니다.

- 공개 주소: https://bluelagoon1222.github.io/Buyback-Korea/
- 데이터: 금융감독원 DART Open API(공시), 네이버 금융(주가 · 상장주식수 · 업종)
- 갱신: GitHub Actions, 평일 08:30 · 19:30 KST (실패 시 22:30 재시도)
- 수집 범위: 2024년 1월 이후 (첫 실행에서 과거분을 모두 받고, 이후에는 최근 공시만 추가)

## 화면 구성

| 영역 | 내용 |
|---|---|
| 요약 타일 | 선택한 기간의 취득 결정(직접+신탁) · 소각 · 처분 금액과 건수, 밸류업 공시 건수 |
| 월별 차트 | 취득 · 소각 · 처분 금액 추이 (막대 위 숫자는 건수) |
| 공시 표 | 유형 탭(전체 · 취득 · 소각 · 처분 · 밸류업), 시장 · 기간 · 시총 대비 최소 비율 · 업종 · 검색 필터, 열 정렬 |
| 기업별 랭킹 | 기간 내 기업별 취득 · 소각 · 처분 합계와 시총 대비 비율, 최근 공시 후 주가 |
| 기업 이력 | 행 클릭 → 해당 기업의 자사주 공시 타임라인과 각 공시의 주가 반응 |

## 지표 정의

- **시총 대비 %** = 공시 금액 ÷ (공시 전일 종가 × 상장주식수)
- **발행주식수 대비 %** = 공시 주식수 ÷ 상장주식수 (신탁계약은 계약금액 ÷ 전일 종가로 환산한 추정치 `≈`)
- **주가 반응** = 공시 전일 종가 대비 익일 · 5거래일 · 20거래일 · 최근 종가 등락률, 작은 글씨는 KOSPI(코스닥 종목은 KOSDAQ) 대비 초과수익
- 월별 합계와 요약 타일은 **정정 · 철회 공시를 제외**하고 계산합니다 (표에서는 "정정" 태그로 표시).

## 파일

```
index.html                  화면 (단일 파일, 외부 라이브러리 없음)
data/latest.json            화면이 읽는 데이터 (자동 생성)
data/status.json            마지막 실행 요약 (자동 생성)
data/state.json             수집 체크포인트 (자동 생성, 삭제해도 다음 실행에서 재구축)
scripts/collect.py          수집 스크립트 (DART Open API + 네이버 금융)
scripts/make_sample.py      화면 확인용 샘플 데이터 생성
scripts/test_offline.py     네트워크 없이 수집 스크립트 전체 흐름을 검증하는 테스트
.github/workflows/update.yml  자동 실행 설정
```

## 설치

`SETUP_GUIDE.md` 를 순서대로 따라가시면 됩니다. DART 인증키는 GitHub Secret `DART_API_KEY` 로 등록합니다.

## 유의사항

공시 원문을 자동 해석하는 과정에서 오류가 있을 수 있으며, 본 사이트는 투자 참고자료로 특정 종목의 매매를 권유하지 않습니다.
수익률은 배당을 제외한 가격 기준입니다. 최종 확인은 표의 DART 링크에서 원문으로 하시기 바랍니다.
